# 휴머노이드·보정·드럼 외형 계약

[English](rig-contract.md) · **한국어**

설계 이유는 [보정](calibration.ko.md)과 [리그 호환성](rig-compatibility.ko.md)을 참고하세요.

## 의미 기반 신체 경계

기본 뼈대와 VRM 0.0/1.0 가져오기는
[NormalizedHumanoidRigAdapter](../../src/rig-humanoid.ts)를 공유합니다.
의미 기반 휴지 관절과 실제 분절 길이를 측정하며, 아바타 이름·모델 파일명·제작자에
따라 애니메이션을 분기하지 않습니다. 원본별 드럼 메시 추출은 외형 어댑터의 책임입니다.

정규화된 휴머노이드 본으로 계산한 뒤 원본(raw) 본으로 명시적으로 변환합니다.
스틱과 접촉 표식은 실제 원본 손 본에 부착합니다. 음수·비균일 스케일의 골격은
거부하며 타점에 닿게 하려고 캐릭터를 암묵적으로 늘리지 않습니다.
선택적 손가락 본이 없으면 그립의 상세도를 낮추되 유효한 신체를 거부하지는 않습니다.

## 좌표와 도구 계약

수치 엔진의 기준은 미터, 위쪽 +Y, 앞쪽 +Z, 해부학적 왼쪽 −X입니다.
VRM 원래 기준에서 왼쪽은 +X입니다. 위치 변환은 `[-x, y, z]`, xyzw 쿼터니언
변환은 `[x, -y, -z, w]`입니다. VRM 골격 루트의 스케일은 양수로 유지합니다.
반사된 루트는 기존 키트·디버그 표시 경로에만 사용합니다.

도구 쿼터니언 네 개는 도구의 로컬 좌표계를 엔진 월드 좌표계로 변환하며 원본 본의
쿼터니언이 아닙니다. 손·소켓 방향과 모델의 휴지 기준을 명시적으로 적용합니다.
float 77개 포즈는 오프셋 73에 협응된 몸통 쿼터니언을 추가합니다. 이는 다섯 번째
도구가 아닌 척추 방향입니다. 휴머노이드 어댑터는 이 회전이 없는 기존 73개 버퍼도
받습니다. 전체 버퍼 배치는 [엔진 계약](engine-contract.ko.md)에서 정의합니다.

변환된 스틱 끝이나 발 로컬 발바닥 소켓을 타점과 비교하여 측정하며 모든 피부·장갑·신발
정점을 검사하지는 않습니다. 수치 골격 대리 형상 검사는 렌더링된 부착 측정과 별개의
검사 경계입니다.

## 수치형 신체 형상

`RigProfile.bodyGeometry`는 선택적인 버전 1 수치 계약입니다.
`source`(`mesh-estimate` 또는 `skeleton-fallback`), 앉은 엔진 월드 좌표의
몸통 `center`, 어깨 오른쪽/위/앞 방향의 `halfExtents`, 좌우 위팔/아래팔
`armRadii`, `handRadii`, 선택적 `handCenters`/`handCapsules`, `sampleCount`를
담으며 길이는 미터입니다. 손 중심과 캡슐 끝점은 도구 좌표계에서 손목에 대한
상대 위치이며 실제로 푼 손목·도구 회전으로 변환합니다. 캡슐이 있으면 오프셋
구보다 우선하고, 선택적 손 형상이 없으면 손목 중심 구를 사용합니다.
[body-geometry.ts](../../src/body-geometry.ts)가 아바타·재질 이름 분기 없이
계산하고 Rust도 독립 검증합니다. 좌석 이동 시 중심을 옮기며, 몸통 방향은
솔버가 사용하는 어깨와 함께 중심을 회전시킵니다.

전체 스킨 메시에서 최대 12,000개 정점을 결정적으로 표본 추출합니다.
유효 스킨 가중치의 65% 이상이 같은 의미 부위에 속해야 하며 추가 본은
가장 가까운 의미 본 조상의 분류를 따릅니다. 머리·다리 부위는 제외합니다.
골반부터 어깨 사이에 유효 몸통 표본이 24개 이상이어야 하며, 부족하면
어깨·분절 기반 추정으로 명시적으로 돌아갑니다. 몸통 너비·깊이는 1–99
백분위에 4mm 여유를, 팔 반지름은 98백분위에 3mm 여유를 사용하고
5–250mm로 제한합니다. 몸통을 메시에서 측정했더라도 팔 표본이 부족하면
해당 팔은 골격 추정을 유지합니다. 손 정점은 정규화된 그립을 raw 본에 적용한
뒤 측정합니다. 결정적인 주성분 축의 1–99백분위 구간과 축에서의 거리 98백분위에
3mm를 더해 캡슐을 만듭니다. 손바닥 방향을 바꾸면 같은 형상을 새 도구 좌표계로
옮기며, 펼친 손의 다른 자세를 다시 측정하지 않습니다.

이는 표본 **외형 영역**이며 해부학적 신체 분류나 모든 정점을 포함한다는
증명이 아닙니다. 몸통·팔에 가중된 의상은 영역을 키울 수 있고 제외한
극단값은 영역 밖에 있을 수 있으며 스키닝은 자세에 따라 달라집니다.
원본 메시·텍스처는 Rust 프로필과 저장 프로젝트에 포함하지 않습니다.
렌더링·시각 검사는 근사 간격과 별도로 검증합니다. [보정](calibration.ko.md)을
참고하세요.

## 모델 가져오기

[vrm-import.ts](../../src/vrm-import.ts)와
[model-import.ts](../../src/model-import.ts)가 사전 검사를 담당합니다.

| 입력 | 허용 범위 |
| --- | --- |
| 캐릭터 | 리소스를 자체 포함하는 VRM 0.0 또는 1.0 `.vrm` 한 개, 최대 50 MiB |
| 필수 신체 | 의미 기반 필수 본 15개, 최대 10,000노드, 유효한 참조·계층과 유한한 변환값 |
| 캐릭터 이미지 | 내장 PNG/JPEG, 최대 64개, 한 변 최대 4096픽셀, 전체 6400만 픽셀 |
| 드럼 부품 | 리소스를 자체 포함하는 정적 `.glb`, 최대 25 MiB, 본체만 있는 지오메트리 전제 |

`VRM.specVersion = "0.0"` 또는 `VRMC_vrm.specVersion = "1.0"`이 명시된 파일만 허용하며, 알 수 없는 버전과 두 확장이 함께 있는 파일은 거부합니다. `.vroid`는 편집 원본이며 앱에
불러오는 실행용 모델이 아닙니다. 일반 휴머노이드 GLB·FBX 매핑은 구현하지 않았습니다.
외부 리소스 참조는 거부하고 메타데이터 링크는 자동으로 가져오지 않고 표시만 합니다.
에셋 사용에는 앱의 MIT 라이선스와 별개로 파일 메타데이터와 원본 이용 조건이 적용됩니다.

VRM 0.0의 `humanBones` 배열은 로딩 전에 이름과 노드 연결의 중복까지 검사합니다.
이전 엄지 `Proximal`/`Intermediate`는 정규화된 `Metacarpal`/`Proximal`로 매핑하고
`Distal`은 유지합니다. 양수 스케일의 +Y축 반회전 래퍼로 원본 루트의 정면을
−Z에서 +Z로 맞춘 **뒤** three-vrm이 기준 변환을 기록합니다. 로더가 나중에 추가하는
정규화 리그를 위해 장면 자체는 항등 변환으로 유지하므로 두 형식 모두 같은 좌표·
그립·배치·평가 경로를 사용합니다.

검사 결과는 원본 메타데이터를 보존합니다. VRM 0.0은 `title`, `author`, `reference`,
`allowedUserName`, `violentUssageName`, `sexualUssageName`, `commercialUssageName`,
`otherPermissionUrl`, `licenseName`, `otherLicenseUrl`을 사용하며 VRM 1.0 라이선스
기본값을 적용하지 않습니다. 누락되거나 잘못된 메타데이터는 권한을 추정하지 않고
알립니다. 원본 문자열과 URL은 텍스트로 표시하며 실행하거나 가져오지 않습니다.

### 포함된 캐릭터 선택

`public/characters/*-provenance.json`이 포함된 각 VRM의 정확한 파일 식별값·제작자·
출처·배포 조건을 관리합니다. 프리셋 선택기는 선택한 동일 출처 파일만 내려받고,
바이트 크기와 SHA-256을 확인한 뒤 로컬 불러오기와 같은 사전 검사·어댑터·자동 배치
트랜잭션에 전달합니다. 포함된 모델이어도 크기·리소스 검사를 우회하거나 본 길이를 바꾸거나 아바타별 동작 규칙을
선택하지 않습니다. 기본 스켈레톤에는 VRM 다운로드가 필요 없으며 로컬 파일은
로컬에 유지됩니다.

AvatarSample_B·Seed-san·Twist 샘플에는 내장 VRM Public License 설정과 추가 조건이
유지됩니다. 모델 정보에 이 조건을 표시하며, Seed-san을 사용한 해당 공개 산출물에는
크레딧이 필요합니다. 앱은 수정된 아바타 데이터를 내보내지 않습니다. 프리셋은 재현
가능한 입력이며 호환성 인증이 아닙니다. Twist의 제한된 배치 탐색 실패와 접근 접촉
경고는 그대로 표시합니다. [모델 안내](../../docs/models.ko.md#포함된-캐릭터-프리셋)에서
개별 출처 기록으로 연결합니다.

## 보정

[kit-calibration.ts](../../src/kit-calibration.ts)는 타점 배치를 검증하고,
[rig-humanoid.ts](../../src/rig-humanoid.ts)는 앉은 신체를 측정·이동합니다.

- 좌석 높이: 0.30–1.20 m. 앞뒤 조절: −0.50–0.50 m.
- 자동 좌석 맞춤은 페달을 고려한 시작 위치이며 충돌 없는 배치 보장은 아닙니다.
- 명시적인 키트 맞춤은 손으로 치는 타점 위치·반지름을 함께 조절합니다. 킥은 유지하고
  일반 하이햇은 페달·기둥·심벌이 연결된 장치로 함께 이동합니다. 탐색 범위와 완전한
  제안의 제한된 의미는 [보정](calibration.ko.md)에서 정의합니다.
- 타점 X는 ±2 m, Y는 0.02–2.50 m, Z는 −0.50–2.50 m 범위입니다.
- 킥·하이햇 페달 높이는 추가로 0.04–0.20 m로 제한합니다.
- 닫힌·열린 하이햇은 움직이는 상단 표면을 공유합니다. 열림과 기계적으로 연결된
  페달은 동일한 결정적 제어 상태를 사용합니다.
- 킥의 엔진 접촉점은 눈에 보이는 앞쪽 드럼 헤드가 아닌 발 페달입니다.
- 배치 변경은 `plan.kit`와 대응하는 `hit.target`을 함께 갱신하고 측정 프로필로
  재계획합니다. 원본 MIDI 데이터와 오디오는 보존합니다.

충돌하는 작업 중에는 보정을 사용할 수 없습니다.
좌석 이동만으로 모든 팔·다리 비율을 수용할 수는 없습니다. 팔다리 길이나 원본 시각을
변경하는 대신 도달 실패를 진단으로 유지합니다.

## 손·발과 반복 가능성

그립은 측정한 손 로컬의 대각선 부착 위치와 사용 가능한 손가락 굽힘을 사용합니다.
기본 `natural` 손바닥 선호는 안쪽과 아래 사이의 사선(두 방향 사이 45°)이며,
위·안쪽·아래는 별도 선택지로 유지합니다. 모든 드러머에게 맞는 유일한 그립이 아닌
공학적 시작 자세입니다. 양쪽 손바닥을 위로 두는 것만으로 완전한 전통 그립을 구현한
것은 아닙니다. 엄지 솔버는 원래 관절에 대한 회전 범위를 지키며 엄지 끝과 스틱의 거리,
끝마디 축과 스틱의 방향 오차를 함께 줄입니다. 손가락 뼈는 늘리지 않으며 선택적
손가락 본이 없으면 그립 세부 표현을 줄입니다. 선택적인 실측 `handFrames`를 사용하면 공통 솔버가
전완·도구를 합친 연결로 각 타점의 손목 방향을 구하여 고정 월드 회전을 대체합니다.
손바닥 방향은 전완 롤이 분담하며 분절 길이와 보정된 그립을 유지합니다. 굽힘 평면은
전방 연주 영역에서 연속적으로 옮기고, 손바닥 롤은 정확한 제약 대신 제한된 선호 조건으로
사용합니다. 해부학적 제한이나 피부 간격을 보장하지는 않습니다. 손 좌표계가 없는
프로필은 이전의 고정 방향 경로를 유지합니다.
손 좌표계가 있으면 미리 계산한 제한된 양팔 선회 곡선이 보정된 손·도구 관계를 유지하며
팔꿈치 평면을 조절합니다. 기존 접촉 경로를 수치 대리 형상으로 평가하며 범위와 남은
충돌 한계는 [보정](calibration.ko.md)에서 정의합니다.

수치 프로필의 선택적 `torsoPivot`은 측정된 정규화 척추 위치이며 좌석과 함께 이동합니다.
평가기에서는 이를 이용해 어깨 루트를 미리 계산한 제한된 몸통 방향 곡선과 일치시킨 뒤
월드 타점으로 양팔을 다시 풉니다. 골반과 다리 루트는 유지합니다. 피벗이 없는 프로필은
몸통 yaw를 0으로 유지합니다. 정확한 범위와 대리 형상의 한계는
[보정](calibration.ko.md)에서 정의합니다.

측정 경로는 [엔진 계약](engine-contract.ko.md)에 따른 악기별 준비 끝점과 velocity 기반
들어 올림·피치를 사용합니다. 프레이즈 배정은 스네어·탐 필인, 악센트 뒤 약한 더블과
그루브에서 크래시로의 역할 유지에 사용 가능한 손을 고려합니다. 동시 원본 타격의 요구를
보존하며 원래 손 배정 스타일을 복원하거나 충돌 없는 팔 경로를 보장하지는 않습니다.

페달 노트가 없어도 발은 보정한 발판 힌지와 접촉을 따릅니다. 뼈를 늘리지 않고
움직이는 발바닥 기준점으로 다리를 풀며 렌더러도 같은 발 쿼터니언으로 발판을
회전합니다. 하나의 절대 시각 하이햇 상태가 발·위쪽 심벌·스틱 타점을 제어합니다.
킥 비터와 발바닥 접촉은 별개입니다. 기계 좌표계는 [장비와 접촉](equipment-contact.ko.md),
지지의 한계는 [보정](calibration.ko.md#발과-지지)에서 정의합니다. 운동학적 표현이며
완전한 heel-up/down 동역학이나 신발 표면 지지 측정은 아닙니다.

평가할 때마다 정규화 포즈와 스프링 상태를 초기화하고, 몸통 회전을 계산된 팔다리
포즈보다 먼저 적용한 뒤 delta 0으로 VRM을 갱신합니다. 표정·시선은 중립이며 노드 제약은 적용합니다.
머리카락·의상의 동적 적분은 이 결정적 계약에 포함되지 않습니다.

## 공통 하드웨어와 교체 가능한 본체

[equipment.rs](../../crates/drum-engine/src/equipment.rs)가 공통 수치 본체·받침대·페달
상자를 정의하고 [kit-hardware.ts](../../src/kit-hardware.ts)는 반환된 형상을 그립니다.
외형 어댑터는 역할과 하드웨어 정체성을 유지하며 쉘·헤드·심벌 본체를 교체합니다.
화면에 표시되는 정적 경계를 계획용으로 측정하므로 외형 교체에 새 배치 갱신이 필요할
수 있지만 원본 MIDI 정체성과 오디오는 유지합니다. 명시적 보정은 본체와 함께
하드웨어를 옮기거나 재구성할 수 있습니다. [장비·접촉 계약](equipment-contact.ko.md)이
형상 검증, 연주 영역 타점, 스틱 전체 검사와 제한된 배치 탐색을 담당합니다. 완료된
맞춤도 정확한 삼각형, 받침대끼리 교차, 피부나 모든 프레임을 보증하지 않습니다.

포함된 어댑터는 모델 정규화에 원본 지오메트리 식별자를 사용할 수 있습니다.
이 식별자가 Rust 계획기나 아바타 솔버로 들어가면 안 됩니다. 로컬 GLB 제작자는
원본 받침대·페달을 제거해야 합니다. 임의의 지오메트리를 신뢰성 있게 자동 분할할 수는 없습니다.

선택적 타격 반응은 절대 곡 시각·velocity에 의존하고 타격 순간의 접촉을 보존합니다.
연주자의 표현과는 별도 기능입니다. 정밀한 클램프, 길이 조절 받침대, 피부 충돌,
명시적 교차 연주 스타일과 완전한 물리 페달 연결은 이 계약이 보장하지 않습니다.
