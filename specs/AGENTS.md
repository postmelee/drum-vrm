# Technical documentation instructions

Follow the [root instructions](../AGENTS.md).

- Keep public technical explanations and contracts in equivalent English/Korean pairs with reciprocal links.
- Update the relevant contract with code changes; preserve exact API names, units, numeric limits and implemented/proposed distinctions in both languages.
- Link original ADRs in `docs/decisions/`, research in `docs/research/` and measured reports in `docs/verification/`. Do not copy their running status or retrospectively rewrite their evidence.
- Preserve meaningful Mermaid diagrams and check their rendering when changed. Add indexes only where they help navigation; split by responsibility rather than an arbitrary category or line count.
