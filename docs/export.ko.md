# 재생·영상에 사용자 WAV 동기화하기

[English](export.md) · **한국어**

이 안내는 저장소 빌드를 설명합니다. 로컬 변경이 공개 사이트에도 반영되었는지는
[버전 표](../README.ko.md#어떤-버전을-사용하고-있나요)에서 먼저 확인하세요.

1. **업로드 · 연주정보**에서 MIDI를 불러오고 연주를 준비합니다.
2. 같은 패널의 **연주 오디오 → WAV 불러오기…**를 선택합니다. 미리보기와 영상에서 WAV가
   합성 드럼 소리를 대체하며 두 소리를 섞지는 않습니다.
3. MIDI 곡 시각을 기준으로 **WAV 시작 위치**를 입력하고 **오프셋 적용**을 누릅니다.
   두 파일을 같은 시간축 시작점에서 내보냈다면 0부터 확인하세요.
   양수는 WAV를 늦추고 음수는 앞당깁니다.
4. 표시된 잘림·무음 정보를 읽고 구별하기 쉬운 타격을 재생한 뒤 곡 끝 근처도
   탐색해 동기화를 확인합니다. 앱은 박자를 자동으로 맞추거나 WAV의 무음을
   제거하지 않습니다. 시작점을 비교할 때 카운트인과 앞부분 무음도 고려하세요.
5. 영상이 필요하면 **내보내기**에서 가능한 형식을 고르고 **영상 추출**을 누릅니다. 선택한 WAV를
   포함하려면 **오디오 없이 내보내기**를 끈 상태로 둡니다. 완료된 파일을 내려받고
   소리와 화면을 확인합니다.

**합성음으로 복원**을 누르면 WAV 선택을 제거합니다. WAV 불러오기가 실패하면
기존 오디오를 유지합니다. 오디오를 바꾸면 이전에 준비한 영상은 무효화되므로 파일이나
오프셋을 바꾼 뒤 다시 출력하세요. WAV와 오프셋 설정은 [로컬 프로젝트 저장·열기](projects.ko.md)로
보존할 수 있으며 파일은 브라우저 안에서 로컬로 처리합니다.

준비 구간 0.5초는 자동으로 더해지므로 오프셋에 다시 더하지 마세요.
오프셋이 +0.25초이면 WAV의 첫 샘플이 출력 0.75초에 시작합니다. 음수 오프셋은
준비 구간도 사용할 수 있으며 출력 0보다 앞선 오디오만 잘립니다. 영상 끝 이후의
오디오도 자르고 부족한 부분은 무음으로 채웁니다. 영상 길이는 선택한 MIDI 트랙으로 결정합니다.

입력은 RIFF/WAVE 파일 하나이며 최대 100 MiB·5분, 모노·스테레오, 8–192 kHz,
비압축 PCM 8/16/24/32비트 또는 Float 32비트를 지원합니다. 브라우저에서
48 kHz 스테레오로 준비합니다. 압축 WAV와 다른 형식은 먼저 변환해야 합니다.
디코더·시간·메모리 상세는 [오디오·출력 계약](../specs/architecture/audio-export-contract.ko.md)에 있습니다.

긴 파일에는 디코딩한 원본, 정렬된 오디오와 인코딩 영상의 메모리가 필요합니다.
가능한 MP4/WebM 조합은 브라우저 코덱에 따라 달라집니다. 오디오 인코더가 실패해도
자동으로 무음으로 바꾸지 않으며, 무음 출력은 별도로 선택합니다.
