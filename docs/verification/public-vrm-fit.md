# Public VRM fitting and visual review

This record covers the common fitting and three-public-model review requested
in [#18](https://github.com/postmelee/drum-vrm/issues/18) and
[#23](https://github.com/postmelee/drum-vrm/issues/23). It starts from integrated
source `c2b06f2b1361848a54b812fe15f1425612327331` on `codex/public-vrm-fit`.
The shipping scope is the baseline fitter plus a corrected cymbal-surface query
and improved review evidence. It does **not** claim improved automatic fitting.
Expanded-search candidates below were measured against rebuilt WASM and rejected
for latency and missing three-model fits. Rendered review and publication are
recorded separately.
This document does not itself establish merge or Pages publication.

## Baseline and inputs

The [integration record](shared-fit-integration.md) preserves the previous
measurements: native fitting succeeded with a 60 mm upward seat adjustment;
AvatarSample B, Seed-san and Twist did not complete the bounded search. Passing
unit tests and previous hand-only fitting results did not establish current
public-model acceptance. Those measurements are not overwritten here.

Use the unchanged approved public assets and their provenance as source identity:

- [AvatarSample B](../../public/characters/avatar-sample-b-provenance.json)
- [Seed-san](../../public/characters/seed-san-provenance.json)
- [Twist](../../public/characters/twist-provenance.json)

The numeric harness checks each asset's bytes and SHA-256 before loading it.
It retains bones, constraints, skins and vertex buffers in an in-memory copy,
removing image/material references only to permit geometry measurement in Node.
No modified model is written. The browser review must use the original textured
assets. The independent Posture Study and Interpretation Study are generated by
`src/demo.ts`; neither depends on a private MIDI file.

The initial regenerated inputs are in
`.local/reference-layout/current-inputs/`. These private measurements are not
committed or an acceptance result. The earlier harness smoke run used stale
ignored WASM and is excluded from this candidate's evidence.

## Acceptance layers

| Layer | Required evidence | What it does not establish |
| --- | --- | --- |
| Source and import | Approved asset identity, current source/WASM hashes, unchanged bone lengths and restored candidate measurements | Successful fitting |
| Accepted static setup | Complete fit, no reported layout/mount violations, unchanged nominal cymbal radii, repeated fit unchanged | Clearance throughout motion |
| Prepared studies | Every arranged hit assigned; source events and accepted layout preserved; repeat preparation equal | Natural-looking performance |
| Numeric motion | Finite ordered/shuffled poses, deterministic marker poses, actual tool markers at planned contacts; sampled proxy minima reported | Continuous mesh/cloth collision freedom |
| Rendered review | Original textured models inspected at the semantic phases from front, top and both sides | Unobserved times or other avatars |
| Publication | Exact deployed commit/WASM and actual Pages checks recorded after approval | Release/tag approval |

Actual stick/sole marker agreement is a contact invariant, not a claim that the
elbow, shoulder, skin or clothing is natural. Proxy violations must be reported
separately even when every planned hit is assigned. A failed bounded fit is not
proof that a model is physically unplayable.

| AvatarSample B | Failed bounded search | Missing hits; deterministic | Failed fallback reviewed |
| Seed-san | Failed bounded search | Missing hits; deterministic | Failed fallback reviewed |
| Twist | Failed bounded search | Missing hits; deterministic | Failed fallback reviewed |

## Reproduction

Rebuild WASM after Rust changes. Record `environment.json` with the results;
having current source files does not establish that ignored WASM is current.
The harness refuses to overwrite evidence directories. Choose a new directory
for each measured candidate.

```sh
npm run build:wasm
node --test scripts/lib/review-landmarks.test.mjs
node scripts/reference-layout-review.mjs --mode inputs --output .local/reference-layout/candidate-inputs
node scripts/reference-layout-review.mjs --mode review --models native,avatar-sample-b,seed-san,twist --output .local/reference-layout/candidate-review
```

For a single fitting investigation, reuse an identified input without silently
remeasuring it:

```sh
node scripts/reference-layout-review.mjs --mode fit --input .local/reference-layout/current-inputs/twist-input.json --output .local/reference-layout/twist-fit-candidate
```

The harness records full geometry and rigid supports, final layout diagnostics,
candidate restoration/application agreement, fit determinism/idempotence,
preparation repeatability, actual contact marker errors and sampled proxy
counts/minima. It samples the existing 30 Hz review times, exact contacts and
source-derived landmarks; those finite samples are not a swept-volume proof.
The JSON explicitly marks rendered review as not performed by the script.

## Browser observations

Choose each public character preset, allow automatic fitting to finish, and
prepare **Posture Study**. Keep the accepted setup unchanged while switching
views and seeking. Inspect both individual poses and playback between them.

The following times describe the independently authored current study. The
script derives landmarks from events, not from a fixture or avatar name;
regenerated JSON is authoritative if the study changes.

| Phase | Time in seconds | Inspect |
| --- | ---: | --- |
| Ready | -0.25 | Relaxed shoulders/elbows, hands, snare relation, knees and feet |
| Groove entry | 2.0 | Crossed-hand ordering and hi-hat approach |
| Sustained groove / backbeat | 4.0 / 3.5 | Settled posture, wrist/grip, body clearance, pedal continuity |
| Tom transfer | 6.5; paths 6.4375, 6.9375, 7.4375, 7.9375 | Whole stick shaft and both arms between surfaces |
| Ride | 8.0 | Reach, torso support and neighboring cymbal/tom clearance |
| Both crashes | 10.5 | Symmetric reach without forced elbow elevation or crossing |
| Ending / recovery | 12.0 / 12.5 | Return to ready posture and instrument clearance |

The normal timeline may clamp to the song duration. The numeric harness also
evaluates final recovery beyond it; do not call an unviewed browser time a visual
pass. For each model, record front/top/left/right observations of skin, sleeves,
whole sticks, shell/support gaps and pedal contact. Distinguish a camera overlap
from an observed 3D intersection. Record limitations rather than inferring a
pass from a clean numeric certificate.

## Findings used during candidate development

The initial snare prior used shoulder/arm/tool reach without the occupied seated
thigh volume. A footprint-clipped lower-limb seed produced isolated snare witnesses
for all three public models. This does not certify the subsequent hi-hat, rack row
or full kit. That candidate-generation experiment is not shipped: it did not
establish acceptable whole-cohort fit/performance. The static certificate remains
unchanged.

A separate rack probe found a real approach problem: the stick shaft was below
its intended tilted head plane, while the arm segments cleared the target. The
query already clips the target body at that plane, so this was not evidence for
removing its collision check. Extending wrist offsets was rejected: the common
+0.6-radian offset already represents about 32 degrees of measured hand/forearm
swing, and larger offsets increased bending without satisfying the same clearance.
A fresh 25/30-degree grip-direction experiment reduced that isolated shaft error
but did not pass the gate; it is not an accepted grip change. The current
45-degree palm diagonal and any future measured fulcrum/estimated palm-heel
replacement require independent finger, thumb and rendered-hand validation.

A ride probe exposed a separate correctness defect: the tangent at a cymbal's
bell could certify a shaft that subsequently crossed the bow. The candidate
queries the authored radial upper profile along the tapered shaft, with exact
radial interval extrema and conservative profile-height bounds. Unresolved
subdivision intervals fail; neither the target body nor the shaft is exempted.
Existing intended terminal-contact allowance and wrist/elbow search limits are
unchanged. This fixes a surface query, not the remaining posture or full-kit fit.
Arm proxies still use enclosing body bounds, and the query does not establish
skin, clothing or arbitrary imported-mesh clearance.

These identify the rejected measured worktree, not an accepted or published commit.

```sh
node scripts/reference-layout-review.mjs --mode fit --input .local/reference-layout/current-inputs/native-input.json --output .local/reference-layout/final-native-fit
```

The native exact-input fit completed in **138.25 seconds**, at unchanged scale
1.0 and seat offset `[0, -0.06, 0]` m, with no reported layout violations or
unresolved equipment. This was one fit after the concurrent Rust regression
process had finished; it did not repeat the native fit or certify native motion.
The latency is a material usability regression, despite the static result. The
expanded rack-row seed search was rejected; the smaller candidate is measured
separately rather than rewriting these results.

The public-only review exited with code 1. Each model reached the 80,000-candidate
limit without a complete fit, and the second fit reproduced the same result.

### Rendered outcome

The final production build was served on localhost:5192 with the same
`0133ab60…755263` WASM. In the in-app Chromium browser (453 × 834), the original
textured presets were selected through the normal Character dropdown. Initial
native automatic fitting was canceled before adoption to retain the nominal
layout used by the numeric review. Each public fit then ran to its reported
failure; no manual offsets or partial proposals were applied. Switching models
reprepared the same Posture Study.

All three models were inspected at ready (−0.25 s), sustained groove (4 s), tom
transfer (6.5 s), both crashes (10.5 s) and ending (12 s). Ready was viewed from
front, top and both sides; later phases used front/left, top/right, front/top and
both sides respectively. Thirty-six screenshots and their hashes are retained in
`.local/reference-layout/minimal-browser-review/manifest.json`. This is narrow
Chromium evidence, not Safari/mobile-device coverage or all-view continuous video.

| Model | Visible result on the retained nominal setup |
| --- | --- |
| AvatarSample B | Hands remained near the same waiting pose at groove, tom and dual-crash checkpoints instead of reaching those instruments. Side views expose the seated leg/floor-tom region needing clearance work. Missing motion agrees with 44 unassigned study hits. |
| Seed-san | Some hand motion is visible, but the dual-crash checkpoint lacks the requested two-arm reach. Side views place the snare close to the thighs; the apparatus on the back is part of this asset, not an extra planned limb. The fit failure remains visible. |
| Twist | Hands stay near the waiting pose through the requested hand-strike checkpoints. The model loads with its original materials and constraints, but this does not make the nominal kit playable; 44 study hits remain unassigned. |

Seek controls, camera changes and preset replacement worked. Seed-san playback
ran from reset to the end; the timeline advanced and ended without a browser
exception, but missing motion prevents a performance pass. Warning/error console
logs were empty after the three-model sequence. Small hands and obscured sleeves
in these whole-kit views cannot certify finger/skin clearance. Apparent top-view
overlap is not independently counted as a solid intersection.

**The requested three-model acceptance is not met.** These observations complete
the failure investigation; they do not close #18/#23 or justify describing this
candidate as a natural-performance update. Pages has not been dispatched. A
separate explicit decision about publishing this known-incomplete test candidate
must identify its exact commit under the release policy.
