# 로컬 프로젝트 저장과 다시 열기

[English](projects.md) · **한국어** · [문서 안내](README.ko.md) · [앱 열기](https://postmelee.github.io/drum-vrm/?lang=ko)

저장소 빌드에서는 준비한 연주와 설정을 로컬 `.drumvrm.json` 파일로 저장할 수 있습니다.
[계측 보고서](calibration.ko.md#문제-구간-검수하기)와는 별도의 파일입니다.

1. MIDI를 준비하고 매핑·해석을 선택한 뒤 캐릭터와 키트를 보정합니다.
   사용할 [WAV](export.ko.md)가 있다면 동기화를 맞춥니다.
2. **파일 · 오디오**의 **프로젝트 저장**을 누릅니다.
   설정을 바꾼 뒤에는 다시 저장하세요.
3. **프로젝트 열기…**로 돌아옵니다. 필요한 파일이 없거나 검증에 실패하면
   현재 세션은 그대로 유지합니다.
4. **원본 파일 연결…**에서 같은 MIDI와 사용한 WAV·VRM·FBX·선택 텍스처·사용자 드럼 GLB를 선택합니다.
   파일 이름은 바뀌어도 되지만 저장한 SHA-256·크기와 내용이 같아야 합니다.
   앱에 포함된 드럼 프리셋은 다시 연결할 필요가 없습니다.
5. 모든 참조가 일치하면 준비한 계획, 트랙 선택, 해석과 명시적인 음표 편집, 좌석, 키트, 외형, 카메라,
   타격 반응, WAV 오프셋, 표시 설정과 재생 위치를 복원합니다. 재생과 탐색으로 확인하세요.

프로젝트에는 **MIDI 노트 데이터와 연주 계획이 포함됩니다.** 원본 연주가 비공개라면
프로젝트도 비공개로 보관하세요. MIDI·WAV·VRM·FBX·텍스처·GLB 원본 파일, 디코딩한 오디오와
모델 도형은 포함하지 않습니다. 프로젝트와 원본 파일을 함께 보관해야 하며,
저장이 에셋 재배포 권한을 주지는 않습니다. 자동 업로드와 브라우저 저장소 자동 저장은 없습니다.

정확한 재열기에는 같은 WASM 엔진 바이너리와 호환되는 체형 측정값이 필요합니다.
버전이나 리그가 다르다는 알림이 나오면 같은 앱 빌드를 사용하거나 원본 MIDI로
새 연주를 준비하세요. 새 엔진이 저장한 프로젝트를 조용히 재해석하지 않습니다.
현재 스키마는 엔진 리비전 사이의 프로젝트 이관을 지원하지 않습니다.
형식과 검증 경계는 [프로젝트 계약](../specs/architecture/project-format.ko.md)에 있습니다.

FBX 프로젝트는 명시적 휴머노이드 본 경로, 미터 변환값, 재질·이미지 연결, 파일 설정 자동 적용/무광/Unlit 표현 선택도 보존합니다. 선택한 PNG/JPEG 모두를 FBX와 함께 보관하세요. 이름만 바뀐 동일 파일도 해시로 허용합니다. [FBX 불러오기](models.ko.md#리깅된-fbx-불러오기)를 참고하세요.
