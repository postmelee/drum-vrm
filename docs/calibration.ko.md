# 좌석·타점·드럼 부품 조절

[English](calibration.md) · **한국어** · [문서 안내](README.ko.md) · [캐릭터 모델 안내](models.ko.md)

좌석과 악기 접촉 위치를 조절해 연주자와 키트를 맞춘 뒤 드럼 몸체의 외형을 바꿉니다. 이 안내는 저장소 빌드를 설명하며 공개 앱의 범위는 [버전별 제공 범위](../README.ko.md#어떤-버전을-사용하고-있나요)에서 확인하세요. 공통 측정값과 동작 계산은 [보정 설계](../specs/architecture/calibration.ko.md)에서 설명합니다.

## 캐릭터를 키트에 맞추기

1. **캐릭터**에서 VRM 1.0 모델을 불러오거나 기본 스켈레톤을 사용합니다. 지원 형식과 한계는 [모델 안내](models.ko.md)에 있습니다. 두 경우 모두 실제 뼈 길이를 측정해 같은 계산을 사용하며, 아바타 이름에 따라 다른 연주 구현을 고르지 않습니다.
2. 새 캐릭터는 페달을 고려한 좌석과 체형별 키트 배치를 자동으로 준비합니다. 완료된 배치 후보를 적용하고 현재 MIDI의 동작을 다시 계산합니다. 완료 알림은 보정 결과이며 피부·의상 충돌이 없다는 보장은 아닙니다. 남은 경고는 **분석**에서 확인하세요.
3. **자동 맞춤**으로 보정을 다시 실행하고 **맞춤 되돌리기**로 직전 설정을 복원합니다. **수동 보정**에는 **좌석 높이 30–120cm**, **앞뒤 위치 −50–50cm**, 손바닥 방향과 기본 배치 복원이 있습니다. 앞뒤 위치가 양수이면 몸이 키트 쪽으로 이동합니다. **좌석만 자동 조정**은 좌석만 변경합니다. 저장한 프로젝트를 다시 열 때는 자동 보정하지 않고 기록된 설정을 복원합니다.
4. **드럼**을 열고 화면이나 선택 목록에서 부품을 고른 뒤 **배치 · 타점 수동 조정**의 **X/Y/Z 타점 위치**를 cm 단위로 조절합니다. X는 좌우(**−200–200cm**, 연주자 오른쪽이 양수), Y는 높이, Z는 앞뒤(**−50–250cm**, 앞쪽이 양수)입니다. 닫힌/열린 하이햇은 같은 심벌 위치를 공유합니다. 하이햇 페달은 별도로 조절합니다. 킥의 타점은 앞면 드럼 헤드가 아닌 발 페달입니다. 현재 공통 하드웨어의 페달 높이는 **4–20cm**, 그 외 타점 높이는 **2–250cm**로 제한합니다. **타점 적용**을 눌러 수정한 위치를 적용합니다.
5. 휴식 상태의 양발을 확인한 뒤 같은 MIDI를 재생하며 스틱이 닿는 순간을 확인합니다. 중요한 타점에 도달하도록 좌석과 타점을 함께 조절합니다. 팔과 다리 비율이 크게 다른 아바타는 좌석 위치만으로 모두 맞출 수 없을 수 있습니다.
6. 갱신된 도달 진단을 읽습니다. 닿지 않는 타격도 원래 소리와 시각을 유지하며, 문제를 숨기려고 뼈를 늘리거나 음표를 이동하지 않습니다. 페달 음표가 없는 MIDI도 발이 페달에 닿지 않으면 알립니다. 여러 시각으로 임의 탐색해 보정된 자세를 확인하세요.

변경은 현재 세션에 적용합니다. 새로고침 후에도 설정을 보존하려면 [프로젝트 저장·열기](projects.ko.md)를 사용하세요. 자동 저장은 없습니다. 로컬 검수 JSON은 문제 분석용 설정·측정값이며 다시 열 수 있는 프로젝트와는 별도입니다. 준비·캐릭터 불러오기·영상 출력 중에는 작업의 일관성을 유지하기 위해 보정 컨트롤이 일시적으로 비활성화될 수 있습니다.

곡 전체 데모는 Logic Drum Kit Designer GM 매핑, 노트 75 카운트인, 짧은 열림/닫힘 하이햇 해석 20%를 명시적으로 적용합니다. 마지막의 추가 스네어는 연주에서 제외하여 **좌우 크래시와 킥**으로 끝납니다. 원본 MIDI 바이트는 바꾸지 않으며, **분석**에서 보존한 음표와 제외 내역을 확인하거나 음표 편집에서 복원할 수 있습니다. 원본에는 양의 note-on 1,760개가 있고 설정한 연주에는 타격 1,720개가 있습니다. 이 집계가 자연스러운 자세나 충돌 없는 움직임을 보장하지는 않습니다. 녹음 WAV나 VRM 캐릭터는 포함하지 않습니다.

이 MIDI는 프로젝트의 공개 배포를 허락받아 포함하며 앱의 MIT 라이선스와는 별개입니다. 정확한 파일과 허용 범위는 [출처 기록](../public/demos/transparent-girl-1-provenance.json), 선택 경계는 [MIDI 계약](../specs/architecture/midi-interpretation.ko.md#포함된-데모의-선택-설정)을 참고하세요. 그 밖에 사용자가 올린 파일은 로컬에 유지합니다.

## 문제 구간 검수하기

**분석 → 자세 · 동기화 검수**에서 정확한 곡 시각을 입력하거나 이전·다음 타격으로 이동합니다. **현재 자세 검사**는 실제 스틱·발 기준점의 오차와 엔진의 몸통·양팔·스틱 근사 간격을 표시합니다. 음수 간격은 근사 영역의 침범 후보이며 피부 관통을 직접 측정한 값은 아닙니다.

**곡 검수**는 30fps 간격과 정확한 타격 시각·그 전후 60ms 표본에서 시간순 평가와 일정하게 섞은 순서의 평가를 비교합니다. 최대 자세 차이와 근사 영역 침범 표본을 표시합니다. 표본 사이 모든 순간의 간격을 증명하는 검사는 아닙니다. 처음 보고된 시각으로 이동하고 여러 카메라에서 실제 외형을 확인하세요.

**현재 스틱 궤적**은 일시정지 시각 주변 최대 0.6초에서 실제 손에 연결된 스틱 끝 기준점 37개를 그립니다. 왼손은 주황, 오른손은 파랑입니다. 다시 그리거나 숨길 때까지 고정되며 영상 출력에는 포함되지 않는 검수용 표시입니다. 충돌 판정은 아닙니다.

**검수 JSON 저장**은 현재 설정, 체형 측정값, 이벤트 집계, 현재 자세·접촉 측정값과 완료된 검수 결과를 로컬로 내려받습니다. 업로드 파일 바이트와 MIDI 노트 원문은 제외합니다. 직접 공유하지 않으면 로컬에만 남으며, 공개하기 전 모델·설정 식별자를 확인하세요. 체형·배치를 바꾸거나 연주를 다시 준비하면 이전 표본 검수 결과는 초기화합니다.

## 발과 손

양발은 시작부터 보정된 킥·하이햇 페달 접촉 위치에 놓입니다. 타격 시에는 발목 위치를 유지하면서 발끝을 조금 들었다가 접촉 위치로 다시 누릅니다. 재생·탐색·영상 출력은 같은 시각 기반 계산을 사용합니다. 이 단순한 발목 동작은 힐업·힐토·더블 페달 주법을 재현하지 않으며 기계적인 페달 시뮬레이션도 아닙니다.

캐릭터 → 수동 보정의 **손바닥 방향**에서 **위**(기본값), **안쪽 · 엄지 위**, **아래**를 선택합니다. 양손에 함께 적용하며 현재 세션에서 좌석을 바꾸거나 다른 캐릭터를 불러와도 선택을 유지합니다. 변경 시 재생을 멈추고 그립을 재보정하며 이전 영상 다운로드를 무효화합니다.

손 안에 대각선으로 고정한 스틱 소켓과 사용 가능한 손가락 본을 사용합니다. 솔버는 중립 손·전완 관계로 각 타점을 따르고 손바닥 방향은 전완 회전으로 분담합니다. 손은 기본적으로 스네어·하이햇 위, 같은 악기를 반복할 때는 그 악기 위에서 대기합니다. Velocity에 따라 들어 올림·손목 움직임이 달라지고, 빠른 스네어에서는 사용 가능한 양손을 쓸 수 있습니다. 공통 절차적 규칙이며 완전한 push-pull·해부학적 제한·충돌 회피는 아닙니다.

이 설정은 **손바닥 방향이며 완성된 전통 그립 주법은 아닙니다.** 전통 그립은 왼손의 받치는 손가락 배치와 오른손의 위에서 잡는 배치가 다릅니다. 일반적인 매치드 그립은 손바닥을 아래나 안쪽으로 향합니다. [Yamaha 그립 안내](https://hub.yamaha.com/music-educators/instruments/perc/a-guide-to-proper-stick-grips/)를 참고하세요. 손가락 본이 없어도 모델은 불러올 수 있지만 그립 표현이 줄어듭니다. 접촉 검사는 실제 스틱 끝과 발 소켓의 변환을 측정하며 모든 피부·신발 정점을 측정하지는 않습니다. 두꺼운 장갑, 큰 손, 특이한 신발 등은 자신의 모델에서 외형을 확인하세요.

짧은 열린 하이햇/발 닫힘 패턴에는 명시적인 해석 옵션으로 왼발의 작은 열림·닫힘 움직임을 사용할 수 있습니다. 의도를 자동 확정하거나 물리적인 심벌 틈을 애니메이션하지는 않습니다. 옵션과 보존되는 원본 근거는 [MIDI 해석](../specs/architecture/midi-interpretation.ko.md)을 참고하세요.

계획기는 **하이햇 오른손·스네어 왼손을 선호**하지만, 도달 범위나 타격 간격에 따라 다른 손을 선택할 수 있습니다. 현재의 선호와 골격 근사 간격 검사가 항상 자연스러운 팔 교차나 피부 간격을 보장하지는 않습니다.

피아노 롤의 음표를 클릭하거나 **선택 음표의 연주 편집 → 현재 시각 음표**를 사용합니다. 제외한 음표를 포함해 동시에 있는 원본 음표를 모두 표시합니다. 손으로 치는 타격의 **자동 / 왼손 / 오른손**, 또는 **이 음표를 연주에서 제외**를 선택하고 적용하세요. 제외 선택을 풀면 자동 해석으로 복원하며 **모든 음표 편집 복원**은 전체 편집을 지웁니다. 지정한 손이 불가능하면 다른 손으로 몰래 바꾸지 않고 진단을 남깁니다. 편집은 원본 MIDI·WAV와 타이밍을 보존하고 원본 이벤트 ID로 기록하며 [로컬 프로젝트](projects.ko.md)에 저장할 수 있습니다. 파생 동작과 합성 미리보기는 바뀌지만 불러온 WAV 녹음은 바뀌지 않습니다.

## 받침대·페달을 유지하며 드럼 몸체 교체하기

드럼 몸체를 바꿔도 공통 받침대·페달 구조를 유지합니다. 모델·크기·회전 변경은 본체를 다시 측정하고 대응 배치와 연주를 자동으로 준비하며, 맞춤 과정에서 관련 받침대 위치가 이동할 수 있습니다. 색상과 타격 반응은 장식적 효과입니다. 원본 MIDI 시각과 합성 소리는 유지됩니다. **분석**에서 남은 경로 알림을 확인하세요. 정적 배치 성공이 움직이는 스틱의 간섭 없음까지 보장하지는 않습니다. [장비·접촉 계약](../specs/architecture/equipment-contact.ko.md)을 참고하세요.

로컬 교체용으로는 외부 참조 없이 리소스를 포함한 **몸체만 있는 정적 단일 `.glb`**(GLB 2.0), 최대 **25MiB**를 준비합니다. 스킨 모델이나 표시할 도형이 없는 파일은 거절합니다. GLTF·FBX·OBJ·BLEND 에셋은 리소스를 포함한 정적 GLB로 먼저 변환하세요. 원본에 포함된 받침대·페달·관계없는 부품은 3D 편집기에서 제거한 뒤 내보내세요. 로더가 임의 하드웨어와 연주 부품을 확실히 구분할 수 없어 그대로 가져오면 받침대 등이 중복될 수 있습니다. 자동 크기 맞춤은 근삿값이므로 실제 표면과 타점을 확인해야 합니다.

프리셋이 원본 모델의 모든 하드웨어를 그대로 포함하지는 않습니다. 공통 장착 방식은 정확한 클램프·길이 조절 스탠드·사실적인 연결부까지 보장하지 않습니다. 가져온 모델에는 개별 이용 조건이 유지됩니다. 외형 교체가 사운드 샘플을 가져오거나 현재 오디오를 바꾸지는 않습니다.

## 프리셋과 타격 반응

키트 프리셋은 자체 도형인 **Studio·Vintage·Electronic**과 **Innerscene·Batoski·smoj** 모델입니다. 별도의 표준·깊은 셸·컴팩트 선택은 선택한 자체 도형 부품의 모양을 바꿉니다. 외부 모델과 조건은 [포함 모델 출처](../public/models/README.ko.md), [에셋 조사](research/drum-assets.md)에 기록합니다. 이 선택으로 새 오디오 샘플이 추가되지는 않습니다. Crash Left와 Crash Right는 각각 타점이 있는 별도 실물 부품이며 프리셋 교체 후에도 이 매핑을 유지합니다.

드럼 설정에서 **타격 반응**을 켜고 **반응 강도**를 조절합니다. 재생 중 반응을 보려면 드럼 편집을 닫으세요. 편집 중이거나 OS의 동작 줄이기가 켜져 있으면 몸체 움직임을 억제합니다. 반응은 타격 velocity를 따르며 음악적 타점과 시각은 유지됩니다. 이는 시각적 피드백이며 키트의 물리 시뮬레이션은 아닙니다.

## 남은 제한

일반 휴머노이드 GLB 매핑, 정밀 피부·발바닥 보정, 충돌 없는 자동 착석, 통제된 작은 체형/큰 체형 VRoid 검증 쌍은 후속 작업입니다. 머리카락·의상 동역학은 탐색·출력 재현을 위해 계속 초기화합니다.
