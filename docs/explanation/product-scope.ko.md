# Drum VRM이 표현하는 것

[English](product-scope.md) · **한국어**

Drum VRM은 음표 이벤트를 확인 가능한 3D 연주로 바꿉니다. MIDI는 음표 번호·시각·velocity를 제공하지만 연주자의 손·그립·자세·악기 음색·의도까지 완전하게 설명하지 않습니다.

따라서 앱이 동작을 명시적으로 선택합니다. 선택 이벤트를 준비하고 가능한 범위에서 손발을 배정한 뒤, 요청한 곡 시점의 자세를 평가해 합성 오디오와 함께 영상을 만듭니다. 지원하지 않는 음표와 현재 체형·키트로 수행하지 못하는 지원 타격은 진단에서 구분합니다.

시각 프리셋이 소리를 결정하지 않으며 캐릭터 모델도 원본 음표를 바꾸지 않습니다. 재생·출력은 공통 시간 기반 평가를 사용하므로 이전에 어떤 프레임을 재생했는지에 의존하지 않고 탐색할 수 있습니다.

## 성공한 결과의 의미

사용할 수 있는 연주는 음악 시각을 보존하고 선택한 동작을 읽을 수 있게 하며 실패를 드러내야 합니다. 스틱 끝이 정확히 닿는 것만으로 편안한 손목·신체 충돌 방지·자연스러운 제스처를 증명하지는 않습니다. 모델 불러오기 성공도 이러한 결과의 증거는 아닙니다.

프로젝트는 독립적으로 구현한 규칙 기반 계산에서 시작합니다. 학습 모션 모델·WAV 동기화·편곡 편집·프로젝트 저장은 별도 작업입니다. 구현 경계는 [기능 제공 범위](../reference/availability.ko.md), 채택된 제품 기준은 [요구사항](../../specs/product/requirements.md)을 참고하세요.
