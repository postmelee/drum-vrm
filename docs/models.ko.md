# 캐릭터 모델 준비하기

[English](models.md) · **한국어** · [문서 안내](README.ko.md) · [앱 열기](https://postmelee.github.io/drum-vrm/?lang=ko)

포함된 VRM 1.0 샘플을 선택하거나 자신의 캐릭터를 불러오고, 이용 조건을 확인한 뒤 드럼 키트에 맞춥니다. 이 안내는 저장소 빌드를 설명하므로 공개 앱을 사용한다면 [버전별 제공 범위](../README.ko.md#어떤-버전을-사용하고-있나요)를 먼저 확인하세요.

## 포함된 캐릭터 프리셋

**캐릭터**를 열고 드롭다운에서 샘플을 고릅니다. 선택할 때만 파일을 내려받으며,
처음 표시되는 스켈레톤에는 모델 다운로드가 필요 없습니다. 로컬 VRM과 같은
불러오기 검사·실측 체형 계산·자동 배치를 사용합니다. **다운로드 취소**로 현재
모델을 유지하면서 프리셋 다운로드를 중단할 수 있습니다.

| 프리셋 | 제작자와 조건 | 용도 |
| --- | --- | --- |
| [AvatarSample_B](../public/characters/avatar-sample-b-provenance.json) | VRoid Project, VRM Public License와 추가 VRoid 샘플 조건 | 일반 캐릭터 검사. 고정된 ChatVRM 파일은 VRM 1.0입니다. |
| [Seed-san](../public/characters/seed-san-provenance.json) | VirtualCast, Inc., VRM Public License, **크레딧 필수** | 다른 체형과 본 제약 구성 검사. |
| [Twist 샘플](../public/characters/twist-provenance.json) | pixiv Inc., VRM Public License | 제약 검사. **자동 배치에는 여전히 제한이 있습니다.** |

연결된 출처 기록에 수정하지 않은 정확한 파일·원본 출처·이용 조건이 있습니다.
이 모델들은 MIT나 CC0가 아닙니다. 선택만으로 자연스러운 접촉이나 충돌 없는 동작이
보장되지는 않습니다. 배치·동작 경고는 **분석**에서 확인하세요. Seed-san 영상에는
제작자 크레딧을 표시해야 하며, 프리셋을 선택해도 내보낸 영상에 크레딧이 자동으로
삽입되지는 않습니다. 앱은 아바타 파일을 내보내지 않습니다.

## 지원 파일

아래 표는 VRM 기준입니다. [리깅된 FBX](#리깅된-fbx-불러오기)는 별도의 설정과 리소스 경계를 사용합니다.

| 항목 | 앱의 제한 |
| --- | --- |
| 캐릭터 형식 | 리소스를 포함한 VRM 0.0 또는 1.0 단일 `.vrm`, 최대 50 MiB |
| 휴머노이드 | 필수 시맨틱 본 15개, 선택적인 손가락 본 수 표시 |
| 장면 | 최대 10,000노드, 올바른 본 참조·계층, 유한한 변환 값 |
| 이미지 | 내장 PNG/JPEG 최대 64개, 한 변 최대 4096픽셀, 전체 6400만 픽셀 |
| 리소스 | 버퍼·텍스처 내장, 외부 파일·URL 참조 불가 |

본 참조는 유효하고 중복되지 않아야 하며 계층에 순환이나 여러 부모가 있으면 안 됩니다. 이는 입력 허용 범위이며 최대 크기 모델이 모든 기기에서 원활하게 표시된다는 뜻은 아닙니다. 기술 상세는 [리그 입력 계약](../specs/architecture/rig-contract.ko.md)을 참고하세요.

VRM 0.0은 직접 불러오며, 체형 맞춤 전에 정면 방향과 이전 엄지 본 이름을 정규화합니다. 알 수 없는 버전이나 두 VRM 확장을 함께 선언한 파일은 거부합니다. `.vroid`는 편집 원본이며 실행용 불러오기 형식이 아닙니다. 일반 캐릭터 GLB·OBJ·BLEND·GLTF 매핑은 지원하지 않으며 바이너리 FBX는 아래의 명시적 연결 절차를 사용합니다. 정적 드럼 GLB 교체는 최대 25 MiB인 [별도 작업](calibration.ko.md#받침대페달을-유지하며-드럼-몸체-교체하기)입니다.

## 불러오고 확인하기

1. **캐릭터** 프리셋을 고르거나 **캐릭터 → VRM / FBX 불러오기…**에서 자신의 `.vrm`을 선택합니다. 로컬 파일은 업로드하지 않고 브라우저에서 처리합니다.
2. **모델 정보 · 이용 조건**을 열어 모델명·제작자·버전·필수 본·손가락 본 수와 이용 조건을 읽습니다. VRM 1.0의 선택적인 권리 항목이 빠졌다면 명세의 기본값을 표시합니다. VRM 0.0은 원본 이용 조건과 재배포·수정 항목을 표시하며, 빠진 값은 미기재로 유지하고 VRM 1.0 기본값으로 대체하지 않습니다. 메타데이터 링크는 자동으로 열거나 조회하지 않습니다.
3. 데모 또는 MIDI를 열고 표시 선택에서 모델·뼈대·모델 + 뼈대·숨김을 고릅니다. 어댑터는 팔다리 길이를 측정하고 기본 스켈레톤과 같은 시맨틱 본 계산을 사용합니다. 손가락 본이 있으면 그립 자세를 적용하며, 선택적인 손가락 본이 없어도 불러올 수 있습니다.
4. 자동 체형 배치 결과를 확인하고 필요하면 [좌석과 타점을 조절](calibration.ko.md)하고 재생·앞뒤 임의 탐색을 비교합니다. 실제 그립, 손에 붙은 스틱 끝, 발과 페달을 확인하세요. 접촉 계측은 도구·발 소켓 기준이며 모든 피부·장갑·신발 정점을 검사하지 않습니다.
5. 프리셋 선택에서 **기본 스켈레톤**를 고르면 스켈레톤으로 돌아갑니다. 불러오기와 복원은 원본 타격 시각을 유지하면서 선택한 체형에 맞춰 현재 MIDI를 다시 계획합니다.

탐색과 출력의 재현성을 위해 매 자세 평가에서 스프링 상태를 초기화합니다. 불러오기 성공만으로 동적인 머리카락·의상 시뮬레이션, 충돌 없는 착석, 정밀 피부·발바닥 보정이나 모든 타점에서 자연스러운 손목이 검증되지는 않습니다. 모델·보정 선택을 다음 세션에도 유지하려면 [로컬 프로젝트](projects.ko.md)를 사용하고 같은 모델 파일을 다시 연결하세요.

## 이전 모델이 하얗게 바래 보일 때

MToon은 밝은 면과 음영 면에 별도의 색상·텍스처를 사용합니다. VRM 0.0 재질에
`_MainTex`는 있지만 `_ShadeColor`가 흰색이고 `_ShadeTexture`가 없다면, 기본
텍스처를 정상적으로 읽어도 음영 영역이 흰색으로 보일 수 있습니다. 가져오기는 해당
재질 설정을 유지합니다. 전체 조명을 바꾸기 전에 원본 재질을 확인하세요.
음영에도 기본 그림을 쓰려는 의도라면 [공식 MToon 안내](https://vrm.dev/en/univrm/shaders/shader_mtoon/)처럼
원본 편집기에서 밝은 면과 음영 면에 같은 텍스처를 연결하고 별도 사본으로 내보내세요.
이 외형 보정은 체형 맞춤이나 접촉 경고를 해결하지 않습니다.

## 리깅된 FBX 불러오기

1. **캐릭터 → 폴더 불러오기…**에서 압축을 푼 캐릭터 패키지 하나를 선택합니다. 하위 폴더의 VRM/FBX와 PNG/JPEG를 찾고, 모델이 여러 개면 선택하게 합니다. 다른 파일은 무시하며 ZIP은 직접 가져오지 않습니다. 또는 **VRM / FBX 불러오기…**에서 바이너리 FBX 7.4/7.5 하나를 선택하고 **파일 검사** 전에 함께 사용할 이미지를 선택합니다. 선택한 패키지에도 기존 파일·이미지 제한을 적용합니다.
2. 아직 연결되지 않은 필수 본을 먼저 표시합니다. 드롭다운에서 선택하며 이미 연결된 본과 연결된 상하 계층에 맞지 않는 후보는 제외합니다. 이름이 일치하는 후보를 먼저 보여주고 **이름이 다른 후보도 표시**에서 다른 유효 후보를 펼칩니다. 현재 연결값은 해제할 수 있도록 유지합니다. **연결된 본 수정**, **선택 본 · 손가락**에서 수정할 수 있습니다. 모호한 이름 중 하나를 임의로 확정하지 않습니다.
3. 본을 선택하면 3D 미리보기에 분홍색으로 위치를 표시합니다. 드래그로 회전하고 스크롤로 확대합니다. 원본 기본 자세를 보여주며 변형이나 연주 품질을 보증하지 않습니다. 적절한 후보가 없다면 연결된 필수·선택 본의 상하 관계를 확인하고 잘못된 연결을 해제하세요.
4. **색상 · 텍스처**를 확인합니다. 파일명에 유일하게 대응하는 기본색 이미지를 제안하며 동점 후보나 일반적인 그림자·노멀·거칠기 맵을 임의로 선택하지 않습니다. 원래 텍스처 연결을 우선합니다. 필요하면 다른 이미지를 고르거나 선택을 해제해 원래 재질로 돌아갈 수 있습니다. **재질 표현**의 기본은 **원본 재질**이며 FBX의 명시적 반사 강도도 반영합니다. **무광 조명**은 반짝임과 환경 반사를 제거하고, **텍스처 그대로 (Unlit)**는 조명·톤 매핑 없이 기본색을 표시합니다. 평면적인 텍스처 중심 미리보기에 맞추려면 Unlit을 선택하세요. 조명 모드의 미리보기는 연주 장면과 조명이 다릅니다. 어떤 모드도 제작 도구의 툰 셰이더를 재현하지 않습니다.
5. **크기 · 파일 정보**에서 미터 변환을 확인할 수 있습니다(센티미터 `0.01`, 미터 `1`). 서 있는 기본 자세를 사용하세요. **캐릭터 적용**은 전체 본 연결을 검증하고 본을 늘리지 않는 자동 맞춤을 실행합니다. 취소·실패 시 현재 캐릭터를 유지합니다.
6. 성공한 설정은 이 브라우저에서 동일한 FBX 바이트에 대해 최근 10개 파일까지 기억합니다. 본·단위·이미지 이름·재질 표현을 저장하며 모델·이미지 내용은 저장하지 않으므로 이미지를 다시 선택해야 합니다. 브라우저 저장소를 사용할 수 없어도 불러올 수 있습니다. 다른 환경에서도 해시 검증으로 다시 열려면 프로젝트를 저장하고 원본 FBX·이미지를 보관하세요.

이미지는 로컬에서 처리합니다. PNG/JPEG 최대 64개·합계 50 MiB, 한 변 4096픽셀, 사용한 내장 이미지까지 합쳐 64M 픽셀 제한입니다. 외부 리소스를 요청하지 않습니다. 추가 파서·장면 제한은 [FBX 불러오기 계약](../specs/architecture/rig-contract.ko.md#fbx-불러오기)이 소유합니다.

FBX 클립, Blender/MMD 제약, 스프링 물리, 툰 노드 셰이더는 연주 입력으로 사용하지 않습니다. 연결하지 않은 보조 본은 로컬 기본 변환을 유지하며 상위 본을 따라가므로 복잡한 비틀림·제어 리그는 다르게 변형될 수 있습니다. 연주자 시점 가림은 연결한 머리 본의 자손을 기준으로 합니다. 가져오기 성공이 옷의 충돌 없음이나 자연스러운 동작을 보증하지 않습니다. FBX에는 VRM 이용 조건 패널이 없으므로 원본 배포처와 모델 조건을 확인하세요. 이 기능에 다운로드한 FBX를 포함하지 않습니다.

개발용으로는 고정된 [ChatVRM AvatarSample_B](https://github.com/pixiv/ChatVRM/blob/b542aa00e19dccf9fc48ba340cf7eee011d2329a/public/AvatarSample_B.vrm), [Twist 샘플](https://github.com/vrm-c/vrm-specification/tree/master/samples/VRM1_Constraint_Twist_Sample), [Seed-san](https://github.com/vrm-c/vrm-specification/tree/master/samples/Seed-san)이 포함된 VRM 1.0 프리셋의 출처입니다. 검사한 파일에는 필수 본과 양손 손가락 본이 있습니다. Twist에는 별도 VRM Public License 설정이 적용되며 three-vrm 코드의 MIT를 따르는 모델이 아닙니다. Seed-san은 크레딧 표시가 필요합니다. 정확한 파일 식별값·조건·검사 결과는 [모델 조사 기록](research/vrm-models.md)에 보존합니다.

## 편집 원본과 실행 파일 보관하기

체형 파라미터 편집용 `.vroid`와 실행용 `.vrm`을 함께 보관하세요. 내려받은 `.vrm`은 원래 편집 원본을 대신하지 않습니다. Studio의 dress-up 기능은 VRM 데이터를 열 수 있습니다. [공식 파일 형식](https://vroid.pixiv.help/hc/en-us/articles/23731198070809-About-file-formats-used-by-VRoid-Studio)과 [dress-up VRM 지원](https://vroid.pixiv.help/hc/en-us/articles/39513464329881-What-is-VRM)을 참고하세요.

체형 적합성을 비교할 통제된 두 모델은 다음처럼 준비합니다.

1. 편집이 허용된 원본에서 시작하고 의상·텍스처 조건을 보관합니다.
2. 의상은 비슷하게 유지하면서 키·팔다리 비율이 다른 작은 체형과 큰 체형의 `.vroid`를 저장합니다. 손목과 다리가 보이는 의상을 우선하고 체형 설정값·Studio 버전을 기록합니다.
3. [공식 내보내기 안내](https://vroid.pixiv.help/hc/en-us/articles/15760756822297-I-want-to-learn-more-about-the-VRM-export-feature)에 따라 모델·제작자 정보를 입력하고 둘 다 **VRM 1.0**으로 내보냅니다.
4. 본 축소 옵션을 사용했다면 내보낸 손·손가락 본을 확인합니다. 같은 MIDI·접촉·좌석 맞춤·임의 탐색·출력 프레임으로 두 모델을 비교합니다.

이는 문서화된 검증 절차이며 완료된 호환성 결과는 아닙니다.

## 사용 목적별 조건 확인하기

| 하려는 일 | 확인할 내용 |
| --- | --- |
| 로컬에서 불러와 평가 | 다운로드·사용 조건, 사용 가능한 사람, 추가 조건 |
| 렌더링한 영상 공개 | 아바타·영상 이용, 해당되는 경우 상업 이용, 표현 제한과 필요한 크레딧 |
| `.vrm`·텍스처·수정 모델 공유 | 별도의 재배포·수정 조건. 영상 이용 허용이 모델 재배포 허용을 뜻하지 않습니다. |

내장 조건과 배포 페이지를 함께 읽으세요. [VRM Public License](https://vrm.dev/licenses/1.0/)에는 모델별 설정이 적용되며, 의상·텍스처·프리셋에 추가 조건이 있을 수 있습니다. [VRoid 모델 이용 안내](https://vroid.pixiv.help/hc/en-us/articles/4405813333657-Can-I-use-the-models-created-with-VRoid-Studio-Stable-Ver-for-commercial-purposes)도 참고하세요. 프로젝트의 MIT는 아바타에 적용되지 않습니다. 내보내기는 모델 크레딧을 자동 삽입하지 않으므로 조건에 따라 공개 영상이나 함께 제공하는 출처 표기에 필요한 크레딧을 넣으세요.

다른 모델은 정확한 재배포 권한을 검토하고 기록하기 전까지 저장소의 추적·공개 파일에 넣지 마세요. `.local/vrm-test-models/`는 Git에서 제외한 로컬 보관 위치이며, 파일을 보관한다고 재배포가 허용되지는 않습니다. 포함된 프리셋은 별도로 검토한 예외입니다.

## 무엇을 검증했나요?
