# 첫 영상 만들기

[English](first-video.md) · **한국어**

내장된 30초 드럼 데모로 업로드 → 준비 → 재생 → 출력 과정을 익힙니다. 공개 앱에서 사용할 수 있는 기본 흐름을 다루며 자세한 구분은 [기능 제공 범위](../reference/availability.ko.md)를 참고하세요.

## 시작하기 전에

데스크톱 Chromium에서 [Drum VRM](https://postmelee.github.io/drum-vrm/)을 엽니다. 영상 출력에는 지원 코덱과 HTTPS 또는 localhost가 필요합니다. 이번 과정에는 MIDI 파일이나 외부 캐릭터 모델이 필요하지 않습니다.

## 준비하고 재생하기

1. **업로드 · 연주정보**에서 **30초 데모**를 선택합니다.
2. 준비가 끝날 때까지 기다립니다. 장면에는 리그와 드럼 키트가, 피아노 롤에는 음표가 나타납니다. 분석 알림을 읽으세요. 지원하지 않는 음표나 선택한 체형·키트로 표현하기 어려운 타격이 있을 수 있습니다.
3. **재생**을 누릅니다. 재생 위치와 스틱을 관찰한 뒤 일시정지합니다.
4. 타임라인에서 다른 시점으로 이동합니다. 다시 재생하거나 처음으로 이동하는 컨트롤을 사용합니다.
5. 정면·위 시점을 살펴봅니다. **드럼**을 열면 키트 정면을 편집할 수 있으며 확인 후 패널을 닫습니다.

데모는 합성 드럼 소리를 사용합니다. DAW 악기 녹음이나 불러온 드럼 모델 고유의 소리는 아닙니다.

## 출력하고 확인하기

1. **내보내기**를 열고 **영상 추출**을 선택합니다.
2. 합성 오디오를 켜 둡니다. 코덱 검사와 프레임 렌더링을 기다리며 필요하면 취소할 수 있습니다.
3. 출력이 끝나면 파일을 내려받아 별도의 영상 플레이어에서 엽니다.
4. 시작과 끝을 포함해 영상과 드럼 소리가 함께 재생되는지 확인합니다.

정확히 30초인 곡은 30fps 기준 923프레임으로 출력됩니다. 준비·여운·프레임 반올림을 포함해 약 30.7667초이며 코덱 검사 결과에 따라 MP4 또는 WebM이 됩니다.

출력을 시작할 수 없다면 [영상 출력](../how-to/export-video.ko.md)을 참고하세요. 다음에는 자신의 MIDI로 [MIDI 지원·출력 제한](../reference/midi-and-export.ko.md)을 확인하며 진행하세요.
