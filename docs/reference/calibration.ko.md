# 보정 컨트롤

[English](calibration.md) · **한국어**

[기능 제공 범위](availability.ko.md)의 개발 기능에 해당합니다. 실제 조절은 [맞춤 절차](../how-to/fit-character.ko.md)를 따르세요.

| 컨트롤 | 범위·의미 |
|---|---|
| 좌석 높이 | 30–120cm |
| 좌석 앞뒤 | −50–50cm; 양수는 키트 방향 |
| 타점 X | −200–200cm; 양수는 연주자의 오른쪽 |
| 타점 Y | 2–250cm; 페달 타점은 4–20cm |
| 타점 Z | −50–250cm; 양수는 앞쪽 |
| 손바닥 방향 | 위(기본값), 안쪽/엄지 위, 아래; 양손에 함께 적용 |
| 자동 맞춤 | 실측 체형·페달 배치로 시작 좌석을 다시 계산 |

열린/닫힌 하이햇은 심벌 타점을 공유하며 하이햇 페달은 별도입니다. 킥 타점은 드럼 헤드가 아닌 발 페달입니다. 화면은 cm, 계산기는 m 단위를 사용합니다.

좌석·타점 변경은 실측 체형의 동작을 다시 계획합니다. 외형 크기·회전은 도달 타점이나 소리를 바꾸지 않습니다. 본 길이와 원본 MIDI 타격 시각을 늘리거나 옮기지 않으며 유효하지 않거나 닿지 않는 배치는 진단합니다.

그립은 손 안에 고정한 스틱 소켓과 사용 가능한 손가락 본을 사용합니다. 손바닥 방향은 완전한 전통 그립이 아닙니다. 발은 페달 접촉 위치를 기준으로 발목 동작을 하며 기계적인 페달판, 완전한 힐업/힐토, 충돌 없는 자세는 제공하지 않습니다.

설정은 현재 세션에만 유지됩니다. 불러오기·준비·출력 중에는 컨트롤이 비활성화될 수 있습니다. 손바닥 방향을 바꾸면 재생을 멈추고 이전 영상 다운로드를 무효화합니다. 탐색·출력 재현을 위해 시간 평가 시 머리카락·의상 스프링을 초기화합니다.

구현 경계는 [리그 계약](../../specs/architecture/rig-contract.md)에 있습니다. [연주 원칙](../explanation/performance-principles.ko.md)은 현재 근사 동작과 계획 중인 주법을 구분합니다.
