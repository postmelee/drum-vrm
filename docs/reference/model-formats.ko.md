# 지원 모델 파일

[English](model-formats.md) · **한국어**

입력 경로를 사용하기 전에 [기능 제공 범위](availability.ko.md)를 확인하세요. 확장자만으로 실제 형식을 판단할 수는 없습니다.

| 목적 | 지원 입력 | 앱 제한 |
|---|---|---|
| 캐릭터 | 리소스를 포함한 단일 VRM 1.0 `.vrm` | 50 MiB, 필수 휴머노이드 본 15개, 유효하고 유한한 계층·변환, 노드 최대 10,000개 |
| 캐릭터 이미지 | 내장 PNG/JPEG | 이미지 최대 64개, 한 변 최대 4096픽셀, 전체 6,400만 픽셀 |
| 드럼 외형 | 리소스를 포함한 정적 GLB 2.0 `.glb` | 25 MiB, 스킨 모델 제외, 표시 가능한 지오메트리 필요 |

리소스는 파일에 포함되어야 하며 외부 파일/URL 참조는 거부합니다. 캐릭터 본 참조는 유효하고 중복되지 않아야 하며 계층에는 순환이나 다중 부모가 없어야 합니다. 선택 사항인 손가락 본 유무는 표시하지만 없어도 모델을 거부하지 않습니다.

앱의 입력 허용 상한이며 모든 기기에서 최대 파일을 원활하게 렌더링한다는 보장은 아닙니다. 캐릭터 메타데이터·라이선스 필드는 확인용으로 표시하며 원출처 조건을 대체하지 않습니다.

## 직접 지원하지 않는 입력

- VRM 0.x: 허용된 경우 VRM 1.0으로 변환하거나 다시 출력합니다.
- `.vroid`: VRoid Studio 편집 원본이며 실행용 모델 입력이 아닙니다.
- 일반 캐릭터 GLB·FBX·OBJ·BLEND·GLTF: 범용 휴머노이드 매핑/불러오기 경로가 없습니다.
- GLTF·FBX·OBJ·BLEND 드럼 에셋: 리소스를 포함한 정적 GLB로 먼저 출력합니다.
- 몸체·받침대가 결합된 로컬 드럼: 자동 의미 분할이 없으므로 공통 하드웨어 교체에는 몸체 전용 파일을 준비합니다.
