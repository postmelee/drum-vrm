# 의존성과 라이선스

[English](README.md) · 한국어

Drum VRM의 자체 코드는 [MIT 라이선스](../../../LICENSE)를 따릅니다. 라이브러리, 모델과 그 원본 자료에는 각자의 이용 조건이 적용됩니다.

정확한 패키지 버전, 소스 압축 파일과 체크섬은 [잠금 의존성 목록](locked.md)에서 확인하세요. 표의 필드명은 영어이며 두 언어 안내가 같은 데이터를 참조합니다.

| 기록 | 내용 |
|---|---|
| [저장소 고지](../../../THIRD_PARTY_NOTICES.md) | 애플리케이션의 전체 고지와 저장소 운영 도구의 출처 |
| [배포 고지](../../../public/licenses.txt) | 웹 애플리케이션과 함께 배포되는 런타임·에셋의 전체 고지 |
| [포함된 모델](../../../public/models/README.ko.md) | 모델 저작자, 원본 링크, 원래 이용 조건과 출처 기록 |

## 목록의 범위

- npm: `package-lock.json`과 설치된 패키지에서 확인한 production 의존성 및 그 전이 의존성입니다. `@types/` 타입 선언 패키지는 실행 코드와 구분합니다. 빌드·검사 도구는 lockfile에 별도로 고정하며 애플리케이션 런타임 의존성 목록에는 넣지 않습니다.
- Rust: `wasm32-unknown-unknown`의 잠금 registry 의존성 그래프입니다. 빌드와 procedural macro 의존성도 보수적으로 포함합니다. 목록에 있다고 모든 부분이 최종 WASM에 연결된다는 뜻은 아닙니다. 표준 라이브러리 고지는 고정된 툴체인에서 가져옵니다.
- 모델: 각 `public/models/*-provenance.json`에 원본, 저작자, 이용 조건, 원본 파일 해시와 런타임 변경 설명을 관리합니다. 생성된 `NOTICE.txt`와 배포 고지는 이 기록을 사용합니다.
- Hyper-Waterfall: 운영 템플릿은 저장소 도구입니다. 고정된 출처와 라이선스는 `.hyper-waterfall/version.json`과 저장소 고지에 기록하며 브라우저 배포물에는 포함하지 않습니다.

## 대응 소스와 원본 고지

Mediabunny의 MPL-2.0 적용 소스 파일은 수정 없이 사용합니다. 목록과 고지는 `src/` 및 원본 라이선스를 포함한 정확한 npm 소스 압축 파일을 연결합니다. 애플리케이션의 별도 MIT 파일은 해당 조건을 변경하지 않습니다.

배포된 `midly` crate에는 라이선스 파일이 빠져 있습니다. 생성기는 기록된 upstream commit의 원문을 보존하고, crate 버전·소스 commit·라이선스 표현식이 모두 맞을 때만 이 예외를 적용합니다. 고정된 출처는 [목록](locked.md#source-evidence-exceptions)에 있습니다.

Rust 표준 라이브러리 고지는 설치된 툴체인의 `COPYRIGHT-library.html`에서 추출합니다. `rust-docs`가 없는 최소 CI 툴체인은 **컴파일러 릴리스와 commit이 모두 같을 때만** 기존 배포 고지를 재사용할 수 있습니다. 새 툴체인에는 해당 버전의 원본 고지가 필요하므로 `rust-docs`를 설치하고 다시 생성하세요.

## 기록 다시 생성하기

잠금 의존성과 고정된 Rust 툴체인이 설치된 상태에서 실행합니다.

```sh
npm run licenses
```

명령은 설치된 라이선스 파일, `package-lock.json`, `Cargo.lock`, `cargo metadata --locked --offline`을 사용합니다. 출처 증거 누락, 의존성 불일치, 모델·라이선스 파일의 바이트 변경이 있으면 실패합니다. 입력 자료에서 의존성 목록, 저장소·배포 고지와 모델 고지를 생성합니다.

라이선스 원문은 제공된 언어와 전체 내용을 보존하며 재작성하거나 번역하지 않습니다. 연구 자료를 인용했다는 사실만으로 라이브러리, 모델, 모션 데이터셋, 음원 샘플이나 모델 가중치가 앱에 포함되는 것은 아닙니다.
