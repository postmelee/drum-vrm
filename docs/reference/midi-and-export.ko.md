# MIDI·출력 제한

[English](midi-and-export.md) · **한국어**

## MIDI 입력

| 항목 | 지원 경계 |
|---|---|
| 파일 | `.mid` / `.midi`, SMF format 0 또는 1, PPQN 시간축 |
| 파일 크기 | 최대 10 MiB |
| 선택 길이 | 선택 트랙의 유효 End of Track까지 최대 300초 |
| 트랙 | 1–512개 |
| 전체 이벤트 | 파일 전체 최대 200,000개 |
| 선택한 지원 타격 | 최대 50,000개 |

SMF format 2·SMPTE 시간축·0 PPQ·손상된 프레임/트랙은 거부합니다. 템포 변경은 선택하지 않은 트랙도 포함해 파일 전체에서 읽습니다. 기본 드럼 후보는 MIDI 채널 10이며 트랙·채널을 확인하고 변경 후 다시 준비하세요.

velocity가 0인 NoteOn은 타격으로 만들지 않습니다. 미매핑 음표는 진단을 남기고 합성·리그 타격에서 제외합니다. 지원하지만 몸으로 연주할 수 없는 타격은 원래 이벤트 시각·소리·타점 강조를 유지합니다. 두 경우는 다릅니다.

## 영상 출력

| 항목 | 동작 |
|---|---|
| 화면 | 1280 × 720, 30fps |
| 소리 | 48kHz 스테레오 합성 드럼 오디오; WAV/DAW 렌더링 아님 |
| 준비 / 여운 | 곡 시작 전 0.5초, 곡 끝 후 0.25초 |
| 프레임 수 | `(0.5 + 곡 길이 + 0.25) × 30`을 올림 |
| 코덱 후보 | MP4 H.264/AAC, WebM VP9/Opus, WebM VP8/Opus 순서 |

실제 설정과 짧은 인코딩·디코딩 시험으로 확인합니다. 오디오 조합 실패를 무음 출력 성공으로 자동 전환하지 않습니다. 코덱 지원은 브라우저·운영체제에 따라 다르며 HTTPS/localhost의 secure context가 필요합니다.

데스크톱 Chromium 검증이 Safari·Firefox·모바일·최대 길이 성능까지 입증하지는 않습니다. PCM과 압축 출력을 메모리에 보관하므로 긴 파일은 더 많은 메모리를 사용합니다. 5분 입력 상한은 기기별 성능 보장이 아닙니다.
