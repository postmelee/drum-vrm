# 자료 출처

[English](README.md) · **한국어**

교육 자료·논문·코드·데이터셋·모델 에셋을 구분합니다. 어느 하나의 라이선스가 다른 배포물까지 자동으로 적용되지는 않습니다. 자료는 독립적으로 설계한 동작 규칙의 근거이며 논문 링크가 코드·가중치·데이터 편입을 뜻하지는 않습니다.
