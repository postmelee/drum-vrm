# Performance instruction sources

**English** · [한국어](performance-instruction.ko.md)

Source verification date: **2026-10-24**. Stable IDs I01–I03 identify the original materials. This register contains links and project summaries; it does not distribute their PDFs, photographs, scores or recordings.

## I01 — Drum Score / Instruction

- **Author:** Keiichi Nagata. **Publisher:** Yamaha Corporation.
- **Source:** [DTX402 Series — Drum Score / Instruction](https://data.yamaha.com/files/download/other_assets/7/1224887/DTX_DrumScore_Instruction_eng.pdf).
- **Locators:** fundamentals, printed pp. 4–7; author profile, p. 51; copyright, final PDF page 52. Page 46 qualifies pedal choice for a particular hi-hat passage.
- **Rights evidence:** © 2018 Yamaha Corporation. No open-content license has been established for this material.
- **Research use:** ready posture, grip, throne placement, heel-down/heel-up support and coordinated playing. Instruction remains contextual; it does not define the project's solver, general joint limits or expression slider.

## I02 — A Guide to Proper Stick Grips

- **Author:** Riley Warren. **Publisher:** Yamaha Music. **Publication:** 2025-12-19.
- **Source:** [A Guide to Proper Stick Grips](https://hub.yamaha.com/music-educators/instruments/perc/a-guide-to-proper-stick-grips/).
- **Locators:** fulcrum, matched, French and traditional grip sections.
- **Rights evidence:** Yamaha copyright notice; no open-content license established.
- **Research use:** grip families, finger placement and wrist/arm roles. A symmetric palms-up setting is not a complete traditional grip.

## I03 — Fix It: Tips for Teaching Snare Drum Basics

- **Author:** Dr. Dave Gerhart. **Publisher:** Yamaha Music. **Publication:** 2021-11-09.
- **Source:** [Fix It: Tips for Teaching Snare Drum Basics](https://hub.yamaha.com/music-educators/instruments/perc/snare-drum-basics-pedagogy/).
- **Locators:** drum height, fulcrum, matched grip and foundation sections.
- **Rights evidence:** Yamaha copyright notice; no open-content license established.
- **Research use:** relate kit placement to comfortable posture and assess basic stroke instruction. Teaching examples are not measured joint-limit datasets.
