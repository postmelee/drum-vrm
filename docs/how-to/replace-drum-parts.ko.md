# 드럼 부품 교체하기

[English](replace-drum-parts.md) · **한국어**

[기능 제공 범위](../reference/availability.ko.md)를 확인하세요. 공개 앱은 기본 외형 교체를 지원하며 개발 흐름에서는 연주 몸체를 공통 받침대·페달과 분리합니다.

1. **드럼**을 엽니다. 편집을 위해 카메라가 정면으로 이동하고 캐릭터는 잠시 숨겨집니다.
2. 키트 프리셋을 선택하거나 부품을 클릭해 외형을 바꿉니다. [프리셋 출처](../reference/presets.ko.md)를 참고하세요.
3. 자신의 부품을 불러오려면 리소스를 포함한 정적 **몸체 전용 GLB**를 준비합니다. 3D 편집기에서 받침대·페달·관계없는 물체를 먼저 제거하세요. 입력 제한은 [형식 참조](../reference/model-formats.ko.md)에 있습니다.
4. 대상 부품을 선택하고 **이 부품의 GLB 불러오기…**를 누릅니다.
5. 자동 맞춤 결과를 확인합니다. 필요하면 외형 크기·회전·색상을 조절합니다. 자동 맞춤은 근삿값이므로 실제 연주 표면과 타점을 비교하세요.
6. 배치를 바꿔야 한다면 [타점 보정](fit-character.ko.md)을 사용합니다. 로컬 교체를 취소하려면 **부품을 프리셋으로 복원**을 누릅니다.

개발 흐름에서는 앱의 받침대·페달을 유지하며 드럼통·헤드·심벌을 교체합니다. 로더는 임의의 결합된 모델을 확실하게 분리하지 못하므로 받침대가 포함된 파일은 하드웨어가 중복될 수 있습니다. 정확한 클램프·길이 조절 스탠드·사실적인 연결부를 보장하지는 않습니다.

외형 크기·회전·색상과 선택형 타격 반응은 음악 타점이나 합성 소리를 바꾸지 않습니다. 타점을 직접 움직이면 배치와 관련 하드웨어가 함께 바뀝니다. 모델 교체는 음원 샘플을 불러오지 않으며 설정은 현재 세션에만 유지됩니다.

악기 움직임은 **타격 반응**을 켜고 **반응 강도**로 조절합니다. 드럼 편집 중이거나 운영체제의 동작 줄이기 설정이 켜져 있으면 움직임을 억제합니다. 반응을 보려면 드럼 패널을 닫으세요.

불러온 에셋에는 원래 이용 조건이 적용됩니다. [모델 이용 안내](obtain-model.ko.md#용도별-조건-확인)에서 영상 공개와 에셋 재배포의 차이도 확인할 수 있습니다.
