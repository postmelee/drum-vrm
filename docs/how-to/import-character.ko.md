# VRM 캐릭터 불러오기

[English](import-character.md) · **한국어**

[기능 제공 범위](../reference/availability.ko.md)에 표시된 VRM 로더가 필요합니다. 이용 조건을 확인한 단일 VRM 1.0 파일을 준비하세요. [모델 확보](obtain-model.ko.md)와 [형식 제한](../reference/model-formats.ko.md)을 참고할 수 있습니다.

1. **캐릭터**에서 **VRM 불러오기…**를 누르고 파일을 선택합니다.
2. 검사와 불러오기가 끝날 때까지 기다립니다. 버전·본·이미지 오류가 표시되면 원본을 수정하고 다시 내보내세요. `.vroid`, `.glb`, VRM 0.x 파일 이름을 `.vrm`으로 바꿔도 변환되지 않습니다.
3. 모델명·제작자·필수 본/손가락 본 개수와 **모델 이용 조건**을 읽습니다. 조건은 파일에 담긴 정보입니다. 생략된 선택 필드는 VRM 명세 기본값으로 표시하며, 이 표시 자체가 별도의 이용 허락은 아닙니다. 링크를 자동으로 가져오지는 않습니다.
4. 데모 또는 MIDI를 불러옵니다. **모델 표시**와 **뼈대 표시**를 각각 조절하며 앉은 자세·손·발을 확인합니다.
5. [좌석·타점 맞추기](fit-character.ko.md)를 따라 조절합니다. 접촉 프레임에 멈추고 앞뒤로 탐색하며 실제 스틱 끝과 페달 접촉을 확인합니다.
6. 필요하면 **기본 리그**로 내장 스켈레톤을 복원합니다. 체형을 바꾸면 기존 MIDI를 다시 계획하며 원본 타격 시각은 유지합니다.

파일은 앱이 업로드하지 않고 브라우저에서 처리합니다. 외부 캐릭터는 앱에 기본 포함하지 않습니다.

불러오기 성공은 입력 조건을 통과했다는 의미이며 모든 자세의 자연스러운 동작을 보장하지 않습니다. 선택 사항인 손가락 본이 없으면 그립 표현이 줄어듭니다. 머리카락·의상 스프링 동작은 탐색·영상 출력의 재현성을 위해 초기화합니다. 피부·옷·신발이 키트와 겹칠 수 있습니다.
