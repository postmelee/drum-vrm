# 영상 출력하기

[English](export-video.md) · **한국어**

먼저 MIDI를 준비하세요. 출력은 미리보기와 같은 시간 기반 연주·합성 오디오를 사용합니다. 화면이나 DAW의 소리를 녹화하는 기능은 아닙니다. 크기·시간·코덱 동작은 [출력 참조](../reference/midi-and-export.ko.md)에 있습니다.

1. 카메라·캐릭터·키트 조절을 마친 뒤 **내보내기**를 엽니다.
2. 오디오를 켜 두거나, 원하는 경우 명시적으로 무음 출력을 선택합니다.
3. **영상 추출**을 누릅니다. 앱은 코덱 지원과 짧은 인코딩·디코딩 시험을 확인한 뒤 전체 영상을 만듭니다.
4. 완료를 기다리거나 필요하면 취소합니다. 취소·실패한 작업은 완료된 다운로드가 아닙니다. 마지막 인코더 정리에는 시간이 걸릴 수 있습니다.
5. 완료 파일을 저장하고 별도의 플레이어에서 확인합니다. 첫 타격·이후 타격·화면·소리·영상 끝을 확인하세요.

개발 버전의 **연주자** 시점은 회전·이동·확대를 고정합니다. 드럼 편집을 열면 정면으로 전환하고 닫으면 이전 카메라로 복원합니다. 출력 전에 시점을 다시 확인하세요.

## 출력에 실패하면

| 증상 | 조치 |
|---|---|
| 출력 API를 사용할 수 없음 | HTTPS 또는 localhost에서 데스크톱 Chromium을 사용합니다. 브라우저·운영체제마다 코덱 지원은 다를 수 있습니다. |
| MP4는 불가능하지만 WebM은 가능 | 제공된 WebM을 저장하세요. 길이·음향 시작점 검사를 통과하지 못한 코덱 조합은 거부합니다. |
| 오디오 조합 거부 | 표시된 이유를 읽으세요. 무음 출력은 자동 성공 대체가 아닌 명시적 선택입니다. |
| 긴 준비 시간·메모리 부담 | 더 짧은 MIDI 선택/파일로 시도하세요. 5분 입력 상한은 성능 보장이 아닙니다. |
| 자세가 이상함 | 미리보기로 돌아가 같은 곡 시점의 접촉을 확인하세요. 출력이 도달성·그립·충돌을 고치지는 않습니다. |

출력에는 준비·여운 구간이 포함됩니다. 모델 조건에 따라 영상 출처 표기가 필요할 수 있습니다. 출력기가 자동 삽입하지 않으므로 공개할 때 추가하세요.
