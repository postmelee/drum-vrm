## 유지할 설계

- 최신 최소 MVP는 MIDI-only + 자체 기본 리그다. WAV·VRM·수동 편집은 M3, 표현·3D 출력·학습은 M4다.
- Rust가 원본 이벤트·타격 의도·손발 계획·시간별 자세를 담당하고, Three.js 리그 어댑터는 이를 표시한다.
- MIDI 시각을 변경하지 않는다. 기본 pre-roll 0.5초와 tail 0.25초를 영상과 합성 오디오에 함께 적용한다.
- 기본 영상은 합성 오디오가 있는 720p30. MP4/WebM 지원을 실제 설정으로 확인하고 명시적인 음소거 선택 외에는 무음 성공으로 대체하지 않는다.
- 타격 접촉 목표 2cm, 시간 정규화 1ms, 출력 A/V 1프레임은 **검증해야 할 계획 수치**다.
- 초기 입력 상한 10MiB·5분과 30초 주 인수 사례를 사용한다. 모든 MIDI/기기의 성능을 보장하지 않는다.

## 확인된 제한과 남은 조사

- MMIP의 라이선스는 공식 검색 색인만 확인했으며 직접 약관·다운로드 조건은 미검증이다. 제품 기본 데이터에서 제외한다.
- DRUMS와 Disney 연구는 논문·공식 페이지를 확인했으나 실행 가능한 공개 코드·가중치의 확보와 조건은 확인하지 못했다.
- MIDIAnimator GPL/Blender 유래 코드는 MVP에 포팅하지 않는다. ARDrum은 #23의 후속 선별 검토 대상이다.
- 자체 소스 MIT 채택은 제안 상태다. 실제 도입 버전의 LICENSE/NOTICE·MPL 대응 소스 제공 조건은 #4/#9에서 배포물과 맞춘다.
- Chromium의 실제 codec·오디오 결합·장시간 메모리, Safari/Firefox 범위는 아직 프로젝트에서 검증하지 않았다.

## 작업 환경 메모

로컬 작업 폴더는 `drum-vrm`이며 Git remote는 위 공개 저장소다. 샌드박스에서 GitHub DNS가 실패할 수 있다. 2026-10-24에는 네트워크 접근 허용 후 기존 `gh` 인증이 정상임을 확인했다. 토큰을 문서나 명령 출력에 노출하지 않는다. 다른 기기에서는 계정·권한을 다시 확인한다.
