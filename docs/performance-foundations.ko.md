# 연주 표현의 원칙과 참고자료

[English](performance-foundations.md) · **한국어**

갱신일: 2026-10-24. 이 문서는 프로젝트의 연구 방향이며 지원 기능 목록이 아닙니다. 주법 프로필과 0–100 표현량 조절은 **계획 단계**입니다. 현재 구현과 한계는 [인수인계](handoff.md)와 [보정 안내](calibration.ko.md)에 기록합니다.

## 기본 원칙

드럼 교육 자료와 애니메이션 연구를 함께 참고하고, 프로젝트의 동작 규칙을 독립적으로 설계·검증합니다. 연주는 음악을 보존하고 연주자의 체형에 맞아야 하며, 선택한 주법이 동작에 드러나야 합니다. 표현을 늘려도 접촉·타격 시각·다음 동작을 유지해야 합니다.

- 원본 MIDI의 음표·시각·velocity를 보존합니다. 시각적 표현량은 소리를 변경하지 않습니다.
- 실측 체형으로 좌석·악기·타점을 맞추며 모든 아바타에 같은 처리를 적용합니다.
- 모든 표현량에서 연주에 필요한 준비·접촉·반동·균형을 유지합니다.
- 그립, 손 배정 스타일, 페달 주법과 표현 동작을 각각 선택합니다.
- 실제 손에 붙은 스틱과 관절 자세·충돌 여유를 측정합니다. 보기 좋은 동작이나 정확한 접촉만으로 통과시키지 않습니다.
- 자료의 설명, 프로젝트의 해석, 구현 상태, 측정 결과를 구분합니다.

교육 자료의 예시는 해당 상황의 출발점이며 모든 체형에 적용할 관절 한계값은 아닙니다. [기술 설계](decisions/0006-technique-and-expression-foundation.md)는 이 원칙을 앞으로 사용할 데이터와 검사 항목에 연결합니다.

## 계획 중인 표현량 조절

| 표현량 | 목표로 하는 시각적 동작 |
| --- | --- |
| 0 | 음표를 연주하는 데 필요한 움직임을 유지하며 부가 동작을 최소화합니다. |
| 50 | 적당한 준비·반동과 프레이즈 강조를 표현합니다. |
| 100 | 선택한 악센트에 큰 동작을 주되, 도달성과 회복할 시간·공간을 확보합니다. |

이는 설계 목표이며 감정의 측정 척도나 구현된 프리셋이 아닙니다. 작은 음의 음악적 역할을 유지하고, 100에서도 모든 타격을 크게 만들지 않습니다. 시간이나 공간이 부족하면 부가 동작부터 줄입니다. 그립과 heel-down/heel-up은 별도 주법이며 표현량만으로 자동 전환하지 않습니다.

강조할 첫 박에는 악보 정보와 명시적인 사용자 지시를 바탕으로 더 큰 준비·회복 동작을 줄 수 있습니다. 마디의 첫 박이 언제나 프레이즈의 절정은 아닙니다. 원본에 두 크래시의 동시 타격이 있으면 추후 두 손과 두 심벌로 표현할 수 있습니다. 한 이벤트에 두 번째 타격을 추가하려면 명시적인 편곡 편집이 필요합니다. 현재는 크래시를 하나의 역할로 합치므로 실제 좌우 심벌을 구분하는 매핑 확장이 선행되어야 합니다.

## 연결된 참고자료

기존 [연구·재사용 대장](research/references.md)은 **DRUMS(R01), MMIP(R02), Implementation of a 3D Virtual Drummer(R03), Disney 드러머 모션 연구(R04), MIDIAnimator(R05), ARDrum(R06), Groove MIDI Dataset(R07)**의 저자·정확한 링크·권리 근거·채택 상태를 보존합니다. 연주 교육, 생성 방법, 도구, 데이터는 서로 다른 근거입니다. 외부 학습 모션 모델을 현재 구현에 편입한 것은 아닙니다.

표준·모델·현재 부족한 부분은 [리그/모션 감사](research/rig-and-studio-audit.md), [VRM 모델 대장](research/vrm-models.md), [드럼 에셋 대장](research/drum-assets.md), [스네어/키트 적합성 분석](research/snare-ready-and-kit-fit.md)에 연결합니다. 코드·논문·데이터·가중치·에셋의 출처와 이용 조건을 각각 관리합니다.

## 구현 순서와 검증

1. **#18:** 체형·키트 실측 보정과 안정적인 준비 위치·접촉 기준.
2. **#20:** 자연스러운 기본 타격, 타점별 손목 방향, 악기별 대기 자세.
3. **#14/#20:** 명시적인 그립·손 배정·페달 주법, 실제 악기 개체 구분과 지지 구조의 동작.
4. **#20/#23:** 제약을 지키는 표현량 0–100과 비교 기록. **#15**에서 추후 설정·표현 지시를 저장.

같은 MIDI와 서로 다른 체형에서 절제된/과장된 사례를 비교하며 시각·접촉·자세·도달성·충돌 여유를 측정합니다. 순차 재생·무작위 탐색·출력 프레임의 자세가 같아야 합니다. 현재 페달 위 발목 동작은 근사 구현이며, 완전한 heel-down/heel-up 동작과 표현량 조절은 미구현입니다. 이 문서는 릴리스·Pages 배포 승인이 아닙니다.
