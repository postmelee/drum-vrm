# MVP 구현과 배포 승인

상태: **승인 대기**. 기록 기준일: 2026-10-24 (Asia/Seoul).

현재 허용된 작업은 개발 계획, 공개 GitHub 저장소 생성, 이슈와 마일스톤 구성, 장기 작업 문서 및 출처·라이선스 조사다. 저장소 공개는 사용자가 2026-10-24에 선택했다.

다음 범위는 계획 검토 후 사용자의 승인 메시지를 받아 시작한다.

- M1과 M2 구현: MIDI 업로드·사전 계산, 확장 가능한 기본 휴머노이드 리그, 재생·일시정지·탐색, 자체 합성 드럼 음향, 720p30 영상 다운로드.
- Rust/WASM + Three.js + 지원 브라우저의 WebCodecs 및 Mediabunny 구성.
- 테스트 통과 후 `postmelee/drum-vrm`의 GitHub Pages에 공개 MVP 배포.
- 자체 소스의 MIT 라이선스 채택 제안. 제3자 구성요소는 각각의 원래 라이선스를 유지한다.

승인 후 기록할 항목: 사용자 승인 날짜와 메시지 요지, 허용 범위, 제외 범위, 담당 이슈. 승인 전에 배포 workflow를 활성화하거나 테스트 사이트를 공개하지 않는다.

M3와 M4는 장기 로드맵이며 첫 MVP 완료 조건이 아니다.
