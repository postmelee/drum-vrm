출처 JSON은 원본·다운로드 링크, 확인 날짜, 모델·라이선스 파일의 정확한 해시, 런타임 변환을 기록합니다. 이 자료로 [NOTICE.txt](NOTICE.txt)와 [배포 고지](../licenses.txt)를 생성하며 `npm run licenses`로 갱신합니다. 원본 GLB와 라이선스 전문을 보존합니다. CC0는 출처 표시가 필수는 아니지만 이력을 위해 제작자를 명시합니다. CC BY의 저자 표시와 변환 내용은 고지에 유지합니다.

모델은 외형을 바꾸며 합성 소리는 바꾸지 않습니다. 런타임 부품 추출·좌표 정규화·배치는 에셋별로 기록합니다. 로컬 드럼 부품은 공통 받침대·페달을 유지할 수 있도록 본체만 포함해야 합니다. [보정 안내](../../docs/calibration.ko.md)를 참고하세요. 외부 캐릭터나 음원 샘플은 포함하지 않습니다.
